# Project Statement: Library Management System

## 1. Problem Statement
Manual library record-keeping leads to unmonitored loans, discrepancies in book availability, and uncollected late fees due to arbitrary borrowing rules.

## 2. Project Scope
The system manages a complete digital library lifecycle featuring:
- Relational catalog tracking across 50 books with real-time status.
- Tiered memberships (Silver, Gold, Platinum) with dynamic loan periods and late fee structures.
- Automated borrow, return, and penalty calculations.

## 3. Target Users
- Library Staff & Administrators
- Library Patrons

## 4. High-Level Features
- Catalog inventory search and status verification
- Tier-based lending restrictions (book quotas and loan duration)
- Automated late penalty calculation and Platinum fee waivers
- Patron profile tracking and transaction logs
